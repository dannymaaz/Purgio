# PR-13 — Conservative startup classification and exact rollback

PR-13 moves Windows startup management behind a backend-authoritative boundary.

## IPC boundary

The renderer sends only the opaque startup item ID to disable or restore an item. Paths, registry locations, commands and original values are no longer accepted from the WebView or returned in the public item model.

Rust rescans the supported registry keys and Startup folders immediately before every change. Unknown, stale or ambiguous IDs fail closed.

## Supported registry origins

Purgio models these origins explicitly:

- HKCU Run and RunOnce;
- HKLM Run and RunOnce;
- HKLM WOW6432Node Run and RunOnce.

Disabling an entry records its exact hive, subkey semantics, value name, raw bytes and registry value type. Restoration writes only to that original origin; RunOnce is never silently converted to Run and HKLM is never degraded to HKCU.

## Durable rollback

Rollback metadata is stored under Purgio's application-data directory with an explicit schema version. Updates use a temporary file followed by an atomic rename. The backup is committed before the original entry is removed.

Startup-folder entries are accepted only as direct, regular, non-symlink children of the user or common Windows Startup folders. The file is copied into Purgio's private backup before the original is removed. Restoration rejects destinations outside those authorized folders and refuses to overwrite an existing entry.

## Conservative recommendations

Applications without an explicit Purgio rule are classified as Unknown/Review and are never recommended automatically. Known hardware, driver and anti-cheat software remains Review.

## Privileges and failures

Machine-wide HKLM operations use their real origin and therefore fail with an actionable Windows permission error when Purgio is not elevated. Purgio does not silently write to a user key or broaden its command surface.

## Verification

- unit tests pin Unknown to Review and retain explicit known-app decisions;
- CI formats `startup.rs` explicitly;
- Windows tests and strict Clippy compile the registry-specific implementation;
- frontend build verifies the reduced ID-only IPC contract.
