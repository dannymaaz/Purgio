# PR-06 — Persisted settings and migration

Purgio stores user preferences and cleanup history in `app_config_dir/state.json` through the Rust backend.

## Persisted state

- schema version
- theme
- language
- cleanup confirmation
- startup-disable confirmation
- sensitive-item visibility
- bounded cleanup history (50 entries)

## Migration

Existing `purgio-theme` and `purgio-clean-history` values are imported once from WebView localStorage. After the backend confirms the migration, the legacy keys are removed.

## Safety

State writes use a temporary file plus backup recovery. Corrupt JSON is quarantined and safe defaults are used. Unknown future schema versions are rejected rather than silently reinterpreted.
